# Referências de experiência

A interface do módulo CDDI utiliza como referência funcional:

- o padrão institucional de acesso, navegação lateral, cabeçalho e cartões do AgSUS Monitora;
- o fluxo guiado, as escalas, o salvamento de rascunho e a área de equipe do Index original do CDDI.

A implementação foi refeita em Next.js e utiliza dados configurados no Supabase, sem reutilizar a base de dados, as variáveis ou o ambiente do AgSUS Monitora.
